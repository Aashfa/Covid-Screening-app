# Covid Screening App

A lightweight static web app for a COVID-19 self-assessment screening flow. The app presents a short questionnaire, gives symptom-based guidance, and explains prevention and general COVID-19 information in a user-friendly interface.

## Overview

This project is built with plain HTML, CSS, and JavaScript, with Bootstrap styling and jQuery for the interactive questionnaire.

The app includes:
- A landing screen with project overview
- A multi-step COVID screening questionnaire
- Symptom and prevention information cards
- Modal-based educational content
- Result states based on answers provided by the user

## Features

- Responsive single-page design
- Bootstrap-powered UI
- Self-assessment symptom checks
- Educational sections on COVID-19, symptoms, and prevention
- Simple result logic for user guidance

## How to Run

Since this is a static web page, you can run it in either of the following ways:

1. Open `index.html` directly in a browser.
2. Or serve it locally:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
